### 👋 About me

I build maintainable systems that connect technology with the people who need it. Currently leading development at an automotive workshop, where I turn manual operations into scalable internal software.

~5 years writing code, 3 professionally — starting in PHP/Laravel backends and evolving toward modern React + AWS serverless architectures.

### 🚀 What I'm working on

- **PaperSheet** — Workshop management platform. Appointment scheduling, vehicle reception, and service order flows. Built with React, TypeScript, Vite, and AWS Amplify Gen 2.
- Deepening AWS expertise — Amplify Gen 2, AppSync, DynamoDB, Lambda, Cognito.
- Architecting permission systems and gamified UX patterns for non-technical users.
